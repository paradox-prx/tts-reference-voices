#118 [closed] EOS token not being found on pretrained base models
URL https://github.com/QwenLM/Qwen3-TTS/issues/118
created 2026-01-28T05:27:30Z by Khochawongwat

### Description

The model rarely wasn't able to produce EOS token and get stuck generating until the max_new_tokens is reached.
Tested on different reference audio and prompt pairs; no pattern discovered. 

**Affected Models**
- Qwen3-TTS-12Hz-1.7B-Base
- Qwen3-TTS-12Hz-0.6B-Base

**Issue**
- ~0.5% of inferences (1/200) fail to generate EOS token
- Generation runs until max_new_tokens limit

**Generation Parameters (default config)**
- temperature: 0.9
- top_p: 1.0
- top_k: 50
- repetition_penalty: 1.05
- max_new_tokens: 8192

**Expected**
- EOS token generated to terminate inference naturally

### Reproduction

No identifiable pattern in triggering inputs.
